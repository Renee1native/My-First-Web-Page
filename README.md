
Visual Design
Gestalt Principles: 1. Proximity keeps related content close together inside each section 2. Similarity gives related section/cards the same styling

Proximity: I used proximity to keep related content close together within each section. For example, the heading, paragraph, and image in the About Me section are grouped together so viewers  can easily see that they belong to the same topic.                                                                                        

Similarity: I used similarity by giving my sections and cards the same background color, border, padding, and rounded corners. This can help viewers recognize that these sections are related.                                                      


color palette 
I used a consistent color palette across the website. I used purple as my primary color for the navigation and footer, white for the section background, and white for the main background and black for the regular text. Using the same colors across the page creates a consistent and organized visual design.
